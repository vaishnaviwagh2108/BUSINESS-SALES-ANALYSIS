Business Sales Dashboard
Project Overview
This project is an interactive **Business Sales Dashboard** created to analyze sales performance across different regions, categories, and states.
The dashboard helps in understanding sales trends, profit margins, and key business insights.
Key Features
* Total Sales and Profit by Region
* Sales Year-to-Date vs Previous Year comparison
* Sales distribution by Category and Region
* State-wise sales and profit analysis
* Interactive filters for Year, Region, State, and Ship Mode
